# 纠错政策

## 如何反馈

请通过 GitHub 的“内容纠错”Issue 模板提交页面链接、问题位置、建议修改和可核验依据。请勿在公开 Issue 中提交个人隐私或密钥。

## 处理流程

1. 记录反馈并保留原页面、来源和提交版本。
2. 重新核对原始资料，必要时联系来源或补充第二个独立来源。
3. 对影响理解的错误及时修改 `updatedAt`，并在正文适当位置说明更正内容和日期。
4. 标题、关键数字、人物归属或事实方向发生实质变化时，不进行无痕修改。
5. 无法核验的内容可暂时撤下；意见分歧若不涉及事实错误，应解释编辑依据。

排版与错别字等不改变含义的小修可直接更正，但仍通过 Git 保留版本记录。
