# 来源政策

## 来源分级

- A 级：原始文件、官方统计、公认的高质量研究出版物，或具有稳定纠错机制的专业媒体。关键事实优先回到这一级来源。
- B 级：具有明确编辑责任、作者和发布日期的行业媒体、地区媒体与研究通讯。重要结论应与 A 级来源或第二个独立来源交叉核验。
- C 级：线索型来源、观点文章、机构博客或尚未建立稳定核验记录的来源。仅用于发现选题，不单独支撑关键事实。

`data/sources.yml` 是人工登记表。示例条目均处于禁用状态，不表示已审查、订阅或获得转载许可。

## 核验与引用

1. 发布前核对标题、作者或发布机构、日期、原始链接和关键事实。
2. 涉及数字、政策文本、直接引语或争议性主张时，回到原始材料；无法核验则明确说明局限或不发布。
3. 不转载来源的完整正文。摘要与正文必须用自己的语言编写，必要的短引语应清楚标注。
4. 不使用版权不明确的图片；采用图片前单独核验授权、署名和使用范围。
5. 每条资讯必须保留可访问的原始链接，并在来源更新或失效时留下编辑记录。
6. 事实陈述、来源观点与本站评论必须在措辞和段落中清楚区分，不把推断写成已证实事实。
